# 뚜껑이여행사 홈페이지

여행사 소개용 홈페이지입니다. 파일 하나(`index.html`)로 되어 있어, 더블클릭하면 바로 열립니다.

## 🌐 공개 주소 (라이브)

https://megastar2.github.io/travel-homepage/

- 접속하면 **비밀번호 창**이 뜹니다. (테스트 단계라서 잠가둠)
- 비밀번호는 `index.html` 맨 아래 `<script>` 안의 `var PW = "..."` 값입니다. 원하는 값으로 바꿀 수 있어요.
- 수정 후 `git push` 하면 약 1분 안에 위 주소에 자동 반영됩니다.

## 📁 구성

| 항목 | 내용 |
|---|---|
| `index.html` | 홈페이지 전체 (디자인·글·잠금 기능이 한 파일에 들어 있음) |
| `images/` | (예정) 사진 모아두는 폴더 |
| `files/` | (예정) PDF·문서 모아두는 폴더 |

## 💻 다른 컴퓨터에서 이어서 작업하기

새 컴퓨터에 **git**이 설치돼 있어야 합니다. (없으면 https://git-scm.com 에서 설치)

1. 작업할 폴더에서 아래 명령으로 내려받기:
   ```
   git clone https://github.com/megastar2/travel-homepage.git
   ```
2. `travel-homepage` 폴더 안에서 `index.html`을 수정.
3. 수정한 내용을 인터넷에 반영(올리기):
   ```
   git add -A
   git commit -m "수정 내용 설명"
   git push
   ```
   ※ 처음 push할 때 GitHub 로그인을 물어볼 수 있습니다. `megastar2` 계정으로 로그인하세요.

> 💡 처음부터 다시 받기 전에, 그 컴퓨터에 이미 폴더가 있다면 `git pull` 로 최신 내용을 먼저 받아오세요. (서로 다른 컴퓨터에서 번갈아 작업할 땐 항상 **시작 전 `git pull`**, **끝낸 뒤 `git push`** 습관!)

## 🔍 미리보기 (선택)

수정 중인 화면을 브라우저로 보려면, 이 폴더에서:
```
python -m http.server 5188
```
실행 후 브라우저에서 `http://localhost:5188` 접속. (그냥 `index.html`을 더블클릭해도 됩니다.)
